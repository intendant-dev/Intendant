# Native focus witness experiment (2026-09-24)

Builds on #952. Fixture-only: bracket fixed production receiver reads with independent native AX focused-element observations. Keep exact objects in memory; publish only status, presence, equality, counts and monotonic duration, never labels, values, addresses or extra PIDs.

Only a supervisor-owned disposable Chrome for Testing process may be observed as target. Human foreground focus is observed, never modified. No application activation, key posting, clipboard access or permission prompts are added. Missing or contradictory native focus is unknown, not unchanged. Sampling is not continuous isolation or an atomic OS routing lock.

A fixed native study includes stable receivers, a controlled fixture-only DOM focus transition, a finite receiver-churn interval and a protected receiver. Collection validity, receiver-read availability and observed changes remain separate. The live plugin and all production guards, timeouts, IAM and input behavior stay unchanged. Native human-concurrent effects are only measured when observed; we do not claim to induce or attribute human activity.
